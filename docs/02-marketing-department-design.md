# Phase 2 — Marketing Department Design

## How the "AI team" really works (transparency note)

The 20 specialists are **role definitions executed by one engine (Claude API)**. Each role has its own mission, responsibilities, KPIs, SOP and tool permissions (`control-center/lib/agents.ts`). An agent acts only when a task exists — created by you, by a content request, by an approval request, or by an enabled scheduled workflow — **and** the API key is configured. There are no hidden background agents. Every run stores the deliverable, token usage, sources retrieved and an audit entry.

Agents **cannot** publish, send, spend or change any external account. Those actions belong to you after approval.

## Operating procedures (all agents)

1. Facts only from: the Control Center database, sources retrieved in the same run (URL cited), or explicitly labelled estimates/assumptions.
2. Research findings must be tagged verified / estimate / assumption. The engine **automatically downgrades** a "verified" claim to "estimate" if its URL was not actually retrieved in that run.
3. Copy never invents statistics, testimonials or certifications; unproven claims are marked `[VERIFY]`.
4. Deliverables land in the agent workspace as **needs review**; you accept, re-brief or cancel.

## Approval process

```
Agent / CEO drafts ──► Approval request ──► Board recommendations (4) ──► CEO: APPROVE / REJECT ──► Execution recorded
                        (campaign, spend,     • AI Marketing Director      (APPROVE locked until    (you launch; system
                         publication,         • Financial & Economic        all 4 exist; REJECT      records status/URL)
                         significant change)  • Legal                       requires a reason)
                                              • Risk Manager
```

- Recommendations are generated by the CMO, Finance, Legal and Risk roles in parallel; if the engine is not configured, you or an advisor can enter them manually — the lock still applies.
- Every request, recommendation and decision is in the audit log with actor and timestamp.
- Approval authorises **only the described action**. Budget changes or new creatives need a new request.
